# 5월 25일 호우 대응 3부처 보도자료 — 검색 페이지 + CSV 추출 도구

2026-05-25 호우 대응에 대해 행정안전부·기상청·경찰청이 낸 (가상) 보도자료 3건을 다루는 두 가지 산출물입니다.

| 파일 | 역할 |
|---|---|
| `index.html` | 정적 웹 페이지. `보도자료데이터.json`을 읽어 부처 카드 표시 · 키워드 검색(결과 N건) · 핵심 수치 비교표 · 외부 리소스(안전한TV YouTube 영상, 공식 사이트 링크) |
| `보도자료데이터.json` | 보도자료 3건 (번호·부처·제목·본문) |
| `solution.py` | 키워드를 입력하면 본문에 그 키워드가 든 보도자료만 `결과_<키워드>.csv`로 저장하는 도구 (표준 라이브러리만 사용) |

## 1. 웹 페이지

빌드 과정 없이 폴더 그대로 올리면 됩니다. 로컬에서 볼 때는 `fetch()`가 동작하도록 간단한 서버를 띄웁니다.

```bash
python -m http.server 8000
```

그다음 http://localhost:8000 을 엽니다. (파일을 더블클릭해 `file://`로 열면 브라우저가 JSON 읽기를 막습니다.)

### 배포

정적 호스팅이면 어디든 됩니다. 폴더 안의 `index.html` · `보도자료데이터.json` · `.nojekyll` 세 파일만 있으면 됩니다.

- **GitHub Pages** — 이 폴더를 저장소 루트에 푸시한 뒤 *Settings → Pages → Source: Deploy from a branch → main / (root)*.
- **Netlify Drop** — https://app.netlify.com/drop 에 폴더를 끌어다 놓으면 바로 주소가 나옵니다.
- **Vercel** — `vercel deploy` (프레임워크 없음, 출력 디렉터리 `.`).

## 2. `solution.py`

```bash
python solution.py "1,820"
```

```
[OK] '1,820' 포함 보도자료 2건 저장 → 결과_1,820.csv
  - [1] 행정안전부 | 5월 25일 전국 호우 대응 — 중대본 1단계 가동
  - [2] 기상청 | 5월 25일 전국 호우특보 발효 및 대응 동향
```

- 인수 없이 실행하면 키워드를 물어봅니다.
- 본문의 마크다운 기호(`**`, `#`, `---`)를 무시하고 찾으므로 `1,820명의`처럼 붙여 써도 됩니다. 영문은 대소문자를 구분하지 않습니다.
- 출력 CSV는 UTF-8(BOM 포함, 엑셀 호환) · 헤더 `번호,부처,제목,본문`.
- 파일명에 쓸 수 없는 문자(`\ / : * ? " < > |`)는 `_`로 바꿉니다. 예: `16:30` → `결과_16_30.csv`
